# 🆘 Support and troubleshooting

## 1. Before asking for help

Start with:
- [README.md](README.md) for project orientation;
- [Installation](docs/installation.md) for local setup;
- [Collection notebook guide](docs/collection-notebook-guide.md) for notebook-specific assumptions;
- [Troubleshooting](docs/troubleshooting.md) for common failures;
- [FAQ](docs/faq.md) for current implementation boundaries.

The repository currently contains two exploratory scraping notebooks and a static frontend. It does not establish a production API, database, or trained sentiment model.

## 2. Where to ask

For reproducible bugs or scoped feature proposals, use the GitHub issue templates. For suspected security problems, credentials, cookies, or exposed personal data, do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## 3. Information to include

A useful support request contains:
- repository branch and commit;
- affected file and notebook cell, if applicable;
- operating system and Python/browser version;
- package versions relevant to the failure;
- expected behaviour;
- actual behaviour;
- exact reproduction steps;
- sanitized traceback or browser console message;
- whether the problem is repeatable.

## 4. Information never to share

Do not attach:
- passwords, API keys, tokens, or cookies;
- browser profiles or session exports;
- reviewer names, profile links, or contact details;
- private or restricted page responses;
- large raw datasets without confirmed publication rights.

Redact sensitive information before sharing diagnostics.

## 5. Feature requests

A useful feature request describes the problem, who is affected, expected behaviour, alternatives considered, acceptance criteria, and data/privacy implications. Avoid requesting a complex framework or model without explaining why the current project needs it.

## 6. Support limitations

This is a community-maintained exploratory project. No guaranteed support response time or service-level agreement is provided. Issues are prioritized by reproducibility, impact, scope, and available maintainer capacity.
