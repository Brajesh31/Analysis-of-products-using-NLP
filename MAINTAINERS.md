## Review areas

The project currently spans exploratory collection notebooks, static frontend assets, and technical documentation. Reviewers should pay particular attention to:
- platform access assumptions and stop conditions;
- selectors that might capture reviewer identities or unrelated page content;
- notebook outputs and embedded metadata;
- data provenance, rating scales, and preprocessing;
- unsupported model, API, and database claims;
- frontend accessibility and broken asset paths.

## Security reports

Do not send secrets or private review data in a public pull request. Follow [SECURITY.md](SECURITY.md) and use private GitHub reporting where available.

## Maintainer availability

This is a community-maintained repository and does not provide a guaranteed response time. Issues and pull requests are prioritized by impact, reproducibility, scope, and available capacity.
