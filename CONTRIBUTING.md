# Contributing

Contributions are welcome when they improve reproducibility, analysis quality, accessibility, or documentation.

- Keep scraping experiments respectful and compliant with the source site's terms.
- Do not commit credentials, cookies, raw personal data, or large generated exports.
- Make notebooks restartable and document package versions, URLs, dates, and known limitations.
- Keep frontend changes accessible and preserve local asset paths.
- Validate HTML/CSS changes with a local static server and run notebook cells against a safe, permitted sample.

Pull requests should explain the change, data sources, privacy implications, validation performed, and any limitations.
