# Installation

## Frontend

No build step is required. From `Frontend/`, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/index.html`.

## Notebooks

Install Jupyter and the packages imported by the notebooks, including `requests` and `beautifulsoup4`. Browser-driven Flipkart collection may require a compatible Selenium/WebDriver setup. Pin versions in a local environment when reproducing historical results.
