# FAQ

## Is this a production sentiment-analysis service?

No. It is an exploratory notebook collection and static product-analysis prototype.

## Can the notebooks scrape any product page?

No. Use only sources and access methods you are authorized to use, respect terms and rate limits, and do not bypass anti-bot or privacy controls.

## Does the frontend compare live prices?

Not currently. The UI describes that concept but contains no committed backend integration.

## Where should generated datasets go?

Keep raw and derived datasets outside Git unless they are small, licensed, non-sensitive, and intentionally versioned. Use local ignored files and document provenance.
