# Roadmap

## Reproducibility

- Add pinned dependency files and a clean notebook setup guide.
- Refactor extraction into small, testable modules with fixtures.
- Add schema validation, deduplication, provenance, and deterministic exports.

## Analysis

- Add language-aware preprocessing and transparent sentiment baselines.
- Compare rule-based and supervised sentiment methods on a reviewed sample.
- Track source drift and provide confidence/coverage metrics.

## Product prototype

- Connect search and listing views to an authorized backend.
- Add accessible keyboard navigation, responsive layouts, and explicit data freshness.
- Keep price and review claims sourced, timestamped, and legally permitted.
